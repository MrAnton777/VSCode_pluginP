# Daylight Profiles

Плагин для VS Code, который меняет тему и размер шрифта по времени суток или вручную.

## Возможности

- Создание, изменение и удаление профилей с темой и размером шрифта.
- Настройка начала дня и ночи и выбор профиля для каждого интервала.
- Ручной выбор профиля через команду или кнопку внизу окна.
- Сохранение настроек и режима после перезапуска.

По умолчанию день начинается в 8:00, ночь — в 19:00. Время задаётся целыми часами. Автоматика проверяет время каждые 30 секунд.

Команда настройки расписания открывает стандартные настройки VS Code: укажите часы и идентификаторы дневного и ночного профилей из списка Profiles.

Ручной профиль действует до включения автоматического режима. Остановка автоматики оставляет текущее оформление.

## Основные команды

- `Daylight Profiles: Управление` — открыть общее меню.
- `Daylight Profiles: Выбрать профиль` — применить профиль вручную.
- `Daylight Profiles: Включить автоматический режим` — включить расписание.
- `Daylight Profiles: Остановить автоматический режим` — остановить переключения.

Если тема не меняется, отключите настройку VS Code `Window: Auto Detect Color Scheme`. Настройки проекта также могут перекрывать тему и размер шрифта.
