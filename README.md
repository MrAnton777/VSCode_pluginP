# Daylight Profiles

Расширение VS Code для переключения профилей оформления по времени суток.

Реализованы проверка запуска, ручное переключение тем, автоматический выбор темы по времени и настройка начала дня и ночи. Профили будут добавлены следующими этапами.

## Запуск

1. Открыть папку `lab_3_ready` в VS Code.
2. Нажать F5 — откроется отдельное окно Extension Development Host.
3. В новом окне открыть палитру команд (`Ctrl+Shift+P` / `Cmd+Shift+P`).
4. Выполнить `Daylight Profiles: Проверить запуск`.
5. Выполнить `Daylight Profiles: Переключить тему`: светлая тема сменится тёмной, тёмная — светлой.
6. Выполнить `Daylight Profiles: Применить тему по времени`: по умолчанию с 08:00 включительно до 19:00 используется Visual Studio Light, в остальное время — Visual Studio Dark.

Используется локальное время компьютера. Команда применения по времени выполняет одну проверку.

## Настройка расписания

Команда `Daylight Profiles: Открыть настройки` открывает параметры расширения:

- `Day Start` — час начала дня, по умолчанию 8.
- `Night Start` — час начала ночи, по умолчанию 19.

Можно указать разные целые числа от 0 до 23. Поддерживается переход через полночь: например, при начале дня в 22 и начале ночи в 6 светлая тема действует с 22:00 до 06:00. Пока время задаётся с точностью до часа.

Настройки сохраняются средствами VS Code. Новое расписание используется при следующей проверке таймера или запуске команды применения по времени.

## Автоматический режим

- Команда `Daylight Profiles: Включить автоматический режим` сразу применяет тему по времени и запускает проверку раз в минуту.
- Повторное включение не создаёт второй таймер.
- Команда `Daylight Profiles: Остановить автоматический режим` останавливает таймер и оставляет текущую тему.
- Ручная команда `Daylight Profiles: Переключить тему` также останавливает автоматику. Для возврата включите автоматический режим снова.
- Состояние автоматического режима сохраняется в `context.globalState`. Если режим был включён, при следующем запуске VS Code расширение применяет тему и запускает таймер заново.
- Ручное переключение и остановка сохраняют выключенное состояние: после перезапуска автоматика не включится сама.
- При отключении расширения таймер освобождается, но сохранённый выбор режима не меняется.
- Если включить автоматику не удалось, например из-за неверного расписания, сохраняется выключенное состояние.

Установка зависимостей и сборка не нужны.

Команда меняет пользовательскую настройку темы. Если включена синхронизация с оформлением системы, отключите `Window: Auto Detect Color Scheme`. Настройки темы конкретного проекта могут перекрывать пользовательскую настройку.

- `.vscode/launch.json` — запуск расширения через F5.
- `README.md` — инструкция.
