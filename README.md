# Daylight Profiles

Расширение VS Code для переключения профилей оформления по времени суток.

Реализованы проверка запуска, ручное переключение тем и автоматический выбор темы по времени. Профили и настраиваемое расписание будут добавлены следующими этапами.

## Запуск

1. Открыть папку `lab_3_ready` в VS Code.
2. Нажать F5 — откроется отдельное окно Extension Development Host.
3. В новом окне открыть палитру команд (`Ctrl+Shift+P` / `Cmd+Shift+P`).
4. Выполнить `Daylight Profiles: Проверить запуск`.
5. Выполнить `Daylight Profiles: Переключить тему`: светлая тема сменится тёмной, тёмная — светлой.
6. Выполнить `Daylight Profiles: Применить тему по времени`: с 08:00 включительно до 19:00 используется Visual Studio Light, в остальное время — Visual Studio Dark.

Используется локальное время компьютера. Команда применения по времени выполняет одну проверку.

## Автоматический режим

- Команда `Daylight Profiles: Включить автоматический режим` сразу применяет тему по времени и запускает проверку раз в минуту.
- Повторное включение не создаёт второй таймер.
- Команда `Daylight Profiles: Остановить автоматический режим` останавливает таймер и оставляет текущую тему.
- Ручная команда `Daylight Profiles: Переключить тему` также останавливает автоматику. Для возврата включите автоматический режим снова.
- При отключении расширения таймер освобождается. После перезапуска окна автоматический режим пока нужно включать заново.

Установка зависимостей и сборка не нужны.

Команда меняет пользовательскую настройку темы. Если включена синхронизация с оформлением системы, отключите `Window: Auto Detect Color Scheme`. Настройки темы конкретного проекта могут перекрывать пользовательскую настройку.

## Файлы

- `package.json` — описание расширения и объявление команды.
- `extension.js` — регистрация и обработчик команды.
- `.vscode/launch.json` — запуск расширения через F5.
- `README.md` — инструкция.
